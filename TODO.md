Реализовано и работает с нашей стороны: поиск клипов встроен в обычный
поиск (сегмент «Video» рядом с Apple/VK/All, `ClipResultsSection` в
`SearchScreen.kt`), `IcmApi.searchClips/resolveClip/pollClipJob/
resolveClipStreamUrl` (резолв с поллингом холодного до 90с), воспроизведение
клипа основным ExoPlayer (`PlayerController.playClip`), видео на `SurfaceView`
вместо обложки в `FullPlayer` (`attachVideoSurface`, флаг `isVideoClip`).
Scope `clips` включён партнёру, premium активен.

**История блокера (решён 23.07.2026):** партнёрский `GET /clips/stream`
ходил в облачный Bot API getFile (лимит 20 МБ) → полные клипы падали с
`404 "file is too big"` на всех качествах; бот ICM при этом был на Local Bot
API (2 ГБ). Отправили менеджеру репро с x-request-id — ICM перевели стрим,
проверено: полный клип 48.33 МБ (1514195718) отдаётся HTTP 200 `video/mp4`
на 720 и 1080, Range работает (206 из начала и середины файла) → перемотка
в ExoPlayer ок. Клиент не менялся — уже был готов.

- [ ] Проверить клипы на устройстве (поиск → Video → полный клип, перемотка).
- [ ] Заметка: quality, похоже, не пережимает (720 и 1080 отдали один файл
