## Как это делалось

Четыре агента, по одному на отчёт. Каждому: прочитать отчёт, прочитать наш код в
своей зоне, выдать ранжированный список реализуемого — не копируя код 1:1.
Правки в код они не вносили намеренно: зоны пересекаются (01 и 03 обе про
лирику, 02 и 04 обе задевают плеер), четыре параллельных редактора сделали бы
кашу. Реализация — потом, батчами по 2-3 пункта.

## Ограничения, заданные владельцем

- Пословных таймингов лирики пока нет: ICM отдаёт их только по премиум-подписке,
  менеджеру написали, ответа ждём. Лирику делаем построчной, с заделом под
  пословные.
- Шрифты SF Pro и иконки SF Symbols использовать нельзя.
- Светлая и тёмная темы обе обязательны.
- Числовые значения — в `ui/theme/LiquidMetrics.kt`, не хардкодом.
- Тумблеры и ползунки в настройках не менять.
- Sing/караоке убран — работал не на всех песнях.
- Пространственное аудио отложено.
- Android Auto отложен: browsable-сервис удалён намеренно, вызывал ANR на
  Honor/Huawei.
- Кроссфейд в форке media3 владельца устраивает — больше не шлифуем.
- UI перенимаем по принципам поведения, не пиксельно: «потом внесём наши правки,
  чтоб не было схожести».
